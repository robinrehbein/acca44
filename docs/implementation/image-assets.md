# Generated demo product images

Created on 2026-10-21 with the built-in ImageGen tool. These are fictional,
unbranded illustrative product mockups, not photographs of the named brands'
actual products. The storefront labels them as AI-generated demo images.
The same generic category image is deliberately reused across demo products;
colors and details do not represent an actual SKU or variant.

with macOS `sips`, quality 85, without cropping, retouching, or compositing.
